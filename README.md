## 配置翻译和开始使用

1. 点击 AlignRead 图标，再点击「设置」。在「配置服务」中选择服务，保存凭据并授权后，点击「设为当前服务」。支持 ChatGPT（OpenAI）、Gemini、Grok、GLM、Kimi、豆包、腾讯混元、DeepSeek、MiniMax、自定义 AI、有道智云和 Google Cloud Translation。 [各服务配置与默认模型](docs/translation-services.md)
2. 打开普通文章或技术文档，在弹窗选择语言，再点击「翻译范围」滑块上的「整页可见文字」或「仅正文」。默认自动检测原文语言，译为简体中文。
3. 点击「翻译模式」滑块上的「双栏对照」或「原位翻译」，再点击对应的开启按钮。默认使用双栏对照。用 Tab 聚焦滑块后，可用方向键切换选项。
4. 开启后，可在译文工具栏或原位翻译的右上角浮条直接切换模式，沿用当前的语言、范围和服务。也可在弹窗选择另一模式后点击切换按钮。

翻译开启期间，原网页更新正文、切换同页标签或更改查询参数时，译文会随可见内容更新。站内切换到其他路径或哈希路由时，清除旧译文并等待新内容。进入新的敏感页面时，翻译会结束，重新开启前需要确认。

可以在工具栏弹窗的「翻译服务」中切换已保存凭据的服务。标为「待授权」的服务需要在设置页完成授权。切换后，重新开启需要的翻译功能即可使用新服务。

在设置页的「双栏阅读」中调整默认语言、翻译范围和阅读偏好。在「站点与缓存」中管理禁用域名和会话缓存，或恢复默认设置。修改偏好后，在所在分类点击「保存设置」。

### 双栏对照

- 直接点击译文文字，左栏会滚动并高亮对应原文段落。用 Tab 聚焦译文段落后，按 Enter 也可定位。点击原文普通文字可反向定位。
- 拖动分隔条或聚焦后按左右方向键调整宽度。右栏可切换同步滚动和悬停高亮，也可暂停、继续或重试失败段落。
- 点击右栏「关闭」或弹窗的「关闭双栏」，恢复原页。视口宽度至少需要 960 CSS px，无法安全分栏时会提示原因。

右栏尽量保留原页的阅读结构。卡片和页脚分组可横排或换行。横排 Tab 保留顺序和可识别的选中态，空间不足时可横向滚动。普通列表保留编号或项目符号，宽表格可独立横向滚动。图片使用占位，图注可翻译。

### 原位翻译

- 译文分批替换原网页上的文字，保留原有链接、图片、样式和页面控件。文字长度变化可能改变换行。代码、编辑区和网页标记为不翻译的区域保留原样。
- 等待翻译或翻译失败的内容继续显示原文。可在弹窗暂停、继续或重试失败项，也可在右上角浮条或弹窗点击「恢复原文」。网站后续写入的内容会保留。
- 原位翻译可用于窄窗口。

### 选词翻译

在扩展弹窗选择语言，点击「开启选词翻译」。选中网页上当前显示的单词或短句，再点击选区旁的「译」。原位翻译开启时，选中译文就会将该译文作为输入。卡片可复制译文或重试，按 Esc 或点击卡片外可关闭。只有点击「译」或重试时，才向当前服务发送选中文字，每次最多 1000 字符。

在扩展弹窗点击「关闭选词翻译」可停用。刷新、地址变化或切换翻译服务后，需要重新开启。

凭据保存在本机扩展存储中，各服务分别授权。设置页可以测试连接，结果和测试时间会保留在本机。表单、可编辑区域及隐藏内容会被排除，识别为敏感的页面需要额外确认。网页翻译缓存仅在当前路径或哈希路由的阅读期间保留。浏览器内部页、iframe 和网页 Canvas 不支持整页翻译。

## PDF、代码与论文

- 在 PDF 标签页打开扩展，点击「打开当前 PDF」。也可点击「打开 PDF」后选择本机文件。阅读器左侧显示原页，右侧显示当前页文字。选择语言后点击「翻译本页」，可取消或重试。翻页后自行决定是否翻译。需登录或禁止跨域读取的文件可先下载再选择。
- PDF 在本机解析，支持 100 MiB 以内、有文字层的文件。识别为公式或代码的整行在译文侧保留原页图像。扫描页可查看原页，翻译前需自行 OCR；加密文件需先解锁。
- 网页代码默认保留。在设置的「双栏阅读」中，可分别开启双栏或原位翻译的代码注释选项。保存后开启相应阅读模式，只有识别出的注释正文参与翻译，字符串、缩进和注释符号保留原样。
- 网页双栏保留 MathML 公式的分式、根号与上下标。对于 KaTeX 和 MathJax，优先使用网站提供的 MathML，其次显示公式文字。原位翻译保留网站的公式节点。
