# AlignRead 隐私政策

本政策适用于 AlignRead Chrome 扩展的双栏与选词翻译功能。扩展没有 AlignRead 自营翻译服务器、用户账户、广告或遥测。用户选择并授权第三方翻译服务后，扩展从浏览器直接向该服务发起翻译请求。

## 网页内容和翻译请求

- 双栏在用户主动开启后读取当前标签页所选范围内的可见文字。选词翻译需在当前标签页开启，只在用户点击「译」或重试时发送选中文字。两种操作都跳过表单、密码、可编辑区域和隐藏内容。检测到登录、支付、管理后台等可能含有敏感内容的页面时，扩展会要求用户再确认一次。
- 启动翻译前需要保存服务凭据、同意发送文本并授予服务域名的访问权限。扩展经 HTTPS 向所选服务发送待译文本、语言参数和该服务所需的身份验证信息。Google Cloud Translation Basic 使用用户填写的 API 密钥。有道智云接收应用 ID 和请求签名，应用密钥留在本机生成签名。请求不附带网页地址、网页 Cookie、DOM 或表单值。可见文本本身仍可能包含个人资料。
- 标题、链接文字、列表、表格和图注等可见文字可能进入所选范围。右栏布局、段落定位和高亮在浏览器本地处理，图片以本地占位显示。
- 「测试连接」使用已保存的凭据发送固定示例文本。连接测试记录保存在本机，仅包含测试时间与结果。
- 使用服务所产生的第三方数据处理和计费由服务提供商管理。参见 [Google Cloud Translation 数据使用说明](https://docs.cloud.google.com/translate/data-usage) 和 [有道智云隐私政策](https://ai.youdao.com/DOCSIRMA/html/agreement/privacy/ydyszc/index.html)。

## 本地保存和删除

- 扩展把翻译凭据、授权、连接测试结果、阅读偏好和禁用站点保存在本机浏览器的扩展存储中。网页无法通过扩展的消息接口读取完整密钥，扩展也不使用 Chrome Sync 同步这些数据。
- 待译文字和译文只保留在当前翻译会话的内存中。双栏的临时缓存可在设置页关闭或清空，识别为敏感的页面跳过缓存。选词文本随选区保留，译文在关闭卡片、切换选区或会话结束时释放。标签页与翻译任务之间的临时授权记录存放在浏览器会话存储中。
- 可以在设置页清除服务凭据、撤销发送同意，或使用「恢复默认设置」清除保存的服务配置和授权。也可在 Chrome 的扩展管理页面撤销服务域名权限或卸载扩展。第三方已收到的数据按该服务的条款处理。

## 浏览器权限

| 权限 | 用途 |
| --- | --- |
| `activeTab` | 用户操作扩展时临时访问当前标签页 |
| `scripting` | 按需挂载双栏或选词界面、读取相应范围内的文字 |
| `storage` | 保存本机配置和当前浏览器会话的任务授权 |
| `translation.googleapis.com`、`openapi.youdao.com` | 分别按需请求，用于调用用户授权的 Google Cloud 或有道智云服务 |

## 数据用途与联系

AlignRead 使用和传输用户数据以提供用户请求的网页翻译及连接测试。用户数据不用于广告、出售、信用评估或借贷。AlignRead 对用户数据的使用和传输遵循 Chrome 网上应用店用户数据政策及其 Limited Use 要求。 [Limited Use 政策](https://developer.chrome.com/docs/webstore/program-policies/limited-use)

如有隐私问题，请通过 Chrome 网上应用店页面列出的开发者联系方式联系维护者。
