# 项目进度

整页翻译跳过代码块和行内代码。双栏可预览只有代码的页面，保留源码排版。 [验收范围](test-plan.md#译文样式覆盖)

设置页在独立标签页打开，按翻译服务、双栏阅读、站点与缓存分区，通过下拉框选择要配置的服务。设置页和工具栏弹窗采用白底，弹窗支持切换已配置的服务。 [设置说明](../README.md#配置翻译和开始使用) · [定向检查](test-plan.md#运行)

弹窗的翻译范围、翻译模式和设置页的默认翻译范围均使用双选滑块，支持点击和方向键切换。 [操作说明](../README.md#配置翻译和开始使用)

双栏、原位和选词翻译共用翻译服务配置。真实接口验收按本地开发步骤执行。 [翻译服务](translation-services.md) · [AI 翻译验证](development.md#ai-翻译验证)

双栏译文保留页头导航和标签的紧凑分组、页签选中态，以及新闻条横排布局。缩窄译文栏时，标签和长链接可换行，页签可在自身区域横向滚动。 [译文样式验收](test-plan.md#译文样式覆盖)

双栏保留代码仓库的文件行、列和源码缩进，并排除收起的菜单内容。 [文件页验收](test-plan.md#真实网页回归)

双栏支持单页应用（SPA）的内容增量更新和站内导航。同页标签和查询参数变化时，右栏更新内容与布局，保留未变译文。切换到其他路径或哈希路由后，右栏等待并翻译新正文。 [SPA 验收](test-plan.md#spa-验收)

原位翻译在当前网页替换可翻译的文字。译文工具栏、原位翻译的右上角浮条和弹窗都可以切换模式。浮条与弹窗均可恢复被替换的原文。 [使用说明](../README.md#配置翻译和开始使用) · [验收范围](test-plan.md#原位翻译验收)
