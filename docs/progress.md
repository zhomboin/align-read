# 项目进度与商店发布

## 商店发布状态

AlignRead 已通过 Chrome 网上应用店审核并上线。商店版本为 **0.1.6**，详情页显示上次更新为 **2026 年 11 月 18 日**。商店版支持双栏阅读和选词翻译。 [商店详情](https://chromewebstore.google.com/detail/alignread/eknjmgokcpffbikmkcnahgmbgcmdjihf?hl=zh-CN) · [版本记录](version.md)

## 主分支已实现

PDF 支持在当前标签页侧边栏逐页翻译、取消和重试。可读取获准访问的本地文件和支持分段的在线 PDF，译文按原文栏序排列。识别出的公式行保留原页图像。网页双栏和原位模式可分别开启代码注释翻译，默认关闭；论文网页保留数学公式。已用同一篇 arXiv 论文的 HTML 和 PDF 验收。 [论文验收](test-plan.md#论文与-pdf-验收)

已验证 arXiv 网页的 Reading mode 可直接双栏翻译。带明确阅读标记和正文区域的网站弹层可在前景翻译。 [阅读模式用法](../README.md#论文网站的阅读模式)

双栏可预览只有代码的页面，保留源码排版。 [验收范围](test-plan.md#译文样式覆盖)

设置页在独立标签页打开，按翻译服务、双栏阅读、快捷键、站点与缓存分区，通过下拉框选择要配置的服务。设置页和工具栏弹窗采用白底，弹窗支持切换已配置的服务。 [设置说明](../README.md#配置翻译和开始使用) · [定向检查](test-plan.md#运行)

弹窗和页内工具栏均可拖动两档滑块、点击模式名称或用方向键切换翻译模式。弹窗与设置页的翻译范围支持点选和方向键。 [操作说明](../README.md#配置翻译和开始使用)

选词翻译和段落翻译在当前标签页独立开关。单独开启段落翻译即可按快捷键翻译选区涉及的每一段。默认 Ctrl，可从弹窗底部进入设置改键，已开启的页面即时生效。选中技术文档中的行内术语也能翻译所属段落。通过目录跳到同页章节后可继续翻译。各段在原话下方显示排队、翻译中或译文。失败时显示原因，可单段重试。 [使用说明](../README.md#段落翻译)

双栏、原位、选词和段落翻译共用翻译服务配置。真实接口验收按本地开发步骤执行。 [翻译服务](translation-services.md) · [AI 翻译验证](development.md#ai-翻译验证)

双栏译文保留页头导航和标签的紧凑分组、页签选中态，以及新闻条横排布局。缩窄译文栏时，标签和长链接可换行，页签可在自身区域横向滚动。 [译文样式验收](test-plan.md#译文样式覆盖)

双栏保留代码仓库的文件行、列和源码缩进，并排除收起的菜单内容。 [文件页验收](test-plan.md#真实网页回归)

双栏支持单页应用（SPA）的内容增量更新和站内导航。同页标签和查询参数变化时，右栏更新内容与布局，保留未变译文。切换到其他路径或哈希路由后，右栏等待并翻译新正文。 [SPA 验收](test-plan.md#spa-验收)

原位翻译在当前网页替换可翻译的文字。译文工具栏、原位翻译的右上角浮条和弹窗都可以切换模式。开启会话缓存后，从这些入口切换都能复用本页已完成且原文匹配的译文。浮条与双栏工具栏显示相同的段落进度、完成状态和失败数。浮条与弹窗均可恢复被替换的原文。 [使用说明](../README.md#配置翻译和开始使用) · [验收范围](test-plan.md#原位翻译验收)

## 暂缓事项

**Chrome 内置阅读模式翻译。** 从 Chrome 菜单打开阅读模式后，全屏视图和侧栏都由浏览器管理。AlignRead 只能翻译底层网页，无法在这两个视图中显示译文。待有可行方案能在内置阅读视图中读取正文并展示译文时，再评估实现。目前可使用 arXiv 网页自身的 Reading mode，或在普通文章页选择「仅正文」开启双栏。 [阅读模式用法](../README.md#论文网站的阅读模式)
