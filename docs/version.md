# 版本记录

## 待发布

- 支持在 arXiv 网页阅读模式和可识别的网站阅读弹层内翻译，只提取阅读正文，关闭双栏后保留网站阅读视图。

- 双栏和原位模式相互切换时，按原文复用当前页已完成的译文。弹窗沿用当前阅读的语言和范围，显式重新翻译会发起新请求。

- PDF 标签页可在侧边栏对照翻译，支持直接读取已授权的本地文件和按需读取在线文件。译文按栏排列，可识别的图表和作者区保留成完整图像，图注继续翻译。独立公式按原图保留矩阵、长求和式、分式、上下标、括号和编号，公式和编号沿用原页位置，带文字下标的条件项随公式显示一次。行内公式按字形和表达式识别，保留公式并翻译周围正文。章节标题分级显示，页码沿用原页的左、中、右对齐。PDF 按页连续滚动，支持相邻页同屏和页码跳转。点击翻译后自动预译后两页，翻页复用本次阅读中的译文。
- 论文网页保留 MathML 的分式和上下标，识别出的 TeX 片段保持原样。
- PDF 保留带编号的多行公式和代码示例，合并正文中的长分式与上下标，整张显示可识别的横线表格。脚注和参考文献按原编号分别显示，保留正文中的链接、代码和段首粗体标签。翻译服务返回异常重复的译文或原样返回较长英文正文时，保留已译段落并提示重试。
- PDF 图注和表注按原文对齐。根据正文基线合并文字层拆出的分式、上下标和段落，包含定义符号的独立公式整条显示。长链接可在窄窗口内换行。
- 网页双栏和原位模式可分别开启代码注释翻译，默认关闭。纯代码页可在双栏保留源码换行与缩进，尝试在工具栏切换原位翻译时保留预览。
- 增加原位翻译。在扩展弹窗切换模式，可在原网页查看译文、重试失败项或恢复原文。双栏仍是默认模式。
- 原位翻译保留原页面链接和样式，支持站内内容更新。恢复时保留网站后续写入的文字。
- 原位翻译浮条实时显示已译段数、总段数和失败数，标明翻译中、暂停或完成状态。
- 翻译模式使用两档滑块，支持拖动、点击两侧名称和方向键。翻译范围可直接点选。
- 可在双栏译文工具栏和原位浮条直接切换翻译模式，沿用当前语言、范围和服务。
- 修复代码仓库文件列表在译文栏被合并的问题，保留文件行、列和源码排版，过滤收起的菜单。
- 按内容宽度紧凑排列译文栏的页头导航、标签和页签，保留原有分组和页签选中态。

## 0.1.7（待商店更新）

- 为双栏和选词翻译加入 ChatGPT（OpenAI）、Gemini、Grok、GLM、Kimi、豆包和腾讯混元的 API 预设。服务分别配置模型、密钥和外发授权。
- 使用统一的服务目录和请求策略，覆盖新预设的设置、连接测试、请求格式和失败场景。
- 双栏译文保留新闻条的标签、分隔符和链接的横排布局，窄栏可在链接内换行。
- 双栏增量翻译 SPA 页面中变化的可见内容。同页标签或查询参数变化时更新右栏布局，保留未变段落的译文。切换到其他路径或哈希路由时清除旧译文，并忽略迟到结果。
- 同页标签切换时可恢复原页重建造成的分栏变化。取消含旧面板内容的在途批次后继续翻译新面板。

## 0.1.6

- 已通过 Chrome 网上应用店审核并上线。商店显示上次更新日期为 2026 年 11 月 18 日。 [商店详情](https://chromewebstore.google.com/detail/alignread/eknjmgokcpffbikmkcnahgmbgcmdjihf?hl=zh-CN)
- 设置使用独立标签页，按功能分区保存，通过下拉框选择要配置的翻译服务。设置页和 440 px 宽的工具栏弹窗均采用白色背景和表单。
- 工具栏弹窗可以切换已保存凭据的翻译服务，并标记待授权的服务。
- 接入 DeepSeek、MiniMax 和自定义 OpenAI Chat Completions 服务，支持双栏和选词翻译、域名授权及连接测试。MiniMax 支持中国站和国际站。
- MiniMax 使用流式响应，区分首次响应超时和翻译中途超时。国际站真实接口已通过复测。
- 更新与功能一致的公开隐私政策页面和 Chrome 网上应用店截图。
