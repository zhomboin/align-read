## 0.1.7

- 为双栏和选词翻译加入 ChatGPT（OpenAI）、Gemini、Grok、GLM、Kimi、豆包和腾讯混元的 API 预设。服务分别配置模型、密钥和外发授权。
- 使用统一的服务目录和请求策略，覆盖新预设的设置、连接测试、请求格式和失败场景。
- 双栏译文保留新闻条的标签、分隔符和链接的横排布局，窄栏可在链接内换行。
- 双栏增量翻译 SPA 页面中变化的可见内容。同页标签或查询参数变化时更新右栏布局，保留未变段落的译文。切换到其他路径或哈希路由时清除旧译文，并忽略迟到结果。
- 同页标签切换时可恢复原页重建造成的分栏变化。取消含旧面板内容的在途批次后继续翻译新面板。

## 0.1.6

- 设置使用独立标签页，按功能分区保存，通过下拉框选择要配置的翻译服务。设置页和 440 px 宽的工具栏弹窗均采用白色背景和表单。
- 工具栏弹窗可以切换已保存凭据的翻译服务，并标记待授权的服务。
- 接入 DeepSeek、MiniMax 和自定义 OpenAI Chat Completions 服务，支持双栏和选词翻译、域名授权及连接测试。MiniMax 支持中国站和国际站。
- MiniMax 使用流式响应，区分首次响应超时和翻译中途超时。国际站真实接口已通过复测。
- 更新与功能一致的公开隐私政策页面和 Chrome 网上应用店截图。
